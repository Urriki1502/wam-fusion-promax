## Documentation conventions

- English is the language of maintained prose, headings and navigation.
- Preserve exact file paths, source identifiers, error codes, test counts, cryptographic hashes, recorded verdicts and immutable evidence.
- Place new design notes near their technical subject; record authoritative acceptance outcomes only in their proper ledger/evidence format.
- Keep historical file names if renaming would break reproducibility or external references. Use this index to provide clear human-readable labels.
- Documentation changes alone do not certify the software or authorize use of real funds.
